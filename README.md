# emrullahd-cakir.github.io

Personal website of Emrullah Dorukhan Çakır, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template and served by GitHub Pages at https://emrullahd-cakir.github.io/.

- Home page: `_pages/about.md`
- CV: `_pages/cv.md`
- Sidebar details (name, email, links, photo): `author:` in `_config.yml`
- Header menu: `_data/navigation.yml`

To add a blog, put posts in `_posts/` (named `YYYY-MM-DD-title.md`) and uncomment "Blog Posts" in `_data/navigation.yml`. To add a portfolio, put project pages in `_portfolio/` and uncomment "Portfolio". To add a photo, put it in `images/` and set `avatar` in `_config.yml`.

Local preview: `bundle install && bundle exec jekyll serve`.
